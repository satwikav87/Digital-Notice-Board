# 📖 Project Overview

Communication is an essential part of every educational institution. Traditionally, schools and colleges display announcements on physical notice boards. This approach is time-consuming, difficult to manage, and often results in students missing important updates.

The **Digital Notice Board** replaces the traditional paper-based notice board with a centralized web application where notices can be published, updated, and viewed digitally.

This project was developed as a **5th Semester Mini Project** to demonstrate the practical use of Python and Django in solving a real-world communication problem.

---

# ❓ Why This Project?

Traditional notice boards have several limitations:

- Students must visit the notice board physically.
- Important notices can be missed.
- Updating notices requires printing new copies.
- Paper notices increase printing costs.
- Old notices create clutter.
- Manual notice management consumes staff time.

To overcome these problems, we developed a web-based Digital Notice Board that makes information available digitally and instantly.

---

# 🎯 Problem Statement

Educational institutions still rely on paper notice boards for communication. Managing paper notices is inefficient, expensive, and inconvenient for both students and staff.

A digital solution is required to improve communication, reduce manual work, and make announcements easily accessible.

---

# ✅ Proposed Solution

The Digital Notice Board provides a simple and effective platform where administrators can manage notices digitally.

Students can view the latest announcements anytime using a computer or mobile device without visiting the physical notice board.

The system improves communication while reducing paperwork and administrative effort.

# 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/satwikav87/Digital-Notice-Board.git
```

### Navigate to the project

```bash
cd Digital-Notice-Board
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Create an administrator account

```bash
python manage.py createsuperuser
```

### Run the development server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
